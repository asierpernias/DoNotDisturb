# Do not disturb

A browser computer vision project that detects whether the user is using headphones by a model I trainde with Google Teachable Machine.

When headphones are detected with enough confidence the webpage activate a Do Not Distub mode. When the headphones are removed the mode is disabled.

## Features

- Real time webcam
- Custom machine learning model that diferenciates between Headphones / No headphones
- Confidence threshold to evit the mode changing because of a single incorrect prediction
- Simulated Do Not Disturb mode
- Confidence percentage
- Session history showing mode changes

## Model

You can try the model [here](https://teachablemachine.withgoogle.com/models/Qbta9feJX/)
